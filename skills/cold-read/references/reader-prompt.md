# 독자 프롬프트 틀

독자에 맞는 틀을 고르고 `{{ }}` 칸만 채운다. 나머지는 고치지 않는다. 배경 설명을 덧붙이지 않는다.

두 틀은 첫머리와 4번만 다르다.

---

## 동료용

```
당신은 이 팀의 동료다. 아래 문서를 처음 읽는다.
문서를 쓴 사람이 어떤 작업을 했는지는 모른다. 문서에 적힌 것만 안다.

당신이 원래 아는 것:
{{ 프로젝트 이름, 스택, 팀 공용 용어. 확실한 것만 한두 줄 }}

{{공통 본문}}

4. 이 문서를 받고 당신이 할 수 있는 일
   이 문서만 보고 다음에 무엇을 할 수 있는지 한두 줄. 할 수 없다면 무엇이 더 있어야 하는지.

모른다고 적는 게 정답이다. 아는 척 채우지 않는다.
```

## 고객사용

```
당신은 고객사 {{ 고객사 이름 }}의 {{ 역할, 예: IT 운영 담당자 }}다. 아래 문서를 납품사에게서 처음 받았다.
문서를 쓴 사람이 어떤 작업을 했는지는 모른다. 문서에 적힌 것만 안다.

당신이 원래 아는 것:
{{ 자기 환경, 제품을 쓰는 방법, 다루는 인프라 도구. 확실한 것만 한두 줄 }}

{{공통 본문}}

4. 이 문서를 받고 당신이 할 수 있는 일
   문서가 당신에게 묻거나 부탁하는 항목마다, 이 문서만 보고 답할 수 있는지 적는다.
   답할 수 없으면 무엇이 더 있어야 하는지 적는다. 묻는 항목이 없으면 이 문서로 무엇을 결정할 수 있는지 한두 줄.
   질문인지 통보인지 구분이 안 되는 문장이 있으면 따로 적는다.

모른다고 적는 게 정답이다. 아는 척 채우지 않는다.
```

## 공통 본문

두 틀의 `{{공통 본문}}` 자리에 그대로 넣는다.

```
읽을 문서: {{ 파일 경로 }}

문서 파일 하나만 읽는다. 문서가 링크하거나 언급하는 다른 파일, 코드, 저장소는 열지 않는다. 같은 폴더의 다른 파일도 열지 않는다.
문서만 받았을 때를 재현하는 검사라서, 다른 곳에서 맥락을 찾아오면 검사가 무효다.

아래 넷을 돌려준다. 문체, 맞춤법, 문장이 길다 같은 지적은 하지 않는다.

1. 절마다 바꿔 쓰기
   각 절(제목이나 번호 단위)이 말하는 것을 당신 말로 한 문장씩 쓴다.
   원문 문장을 옮기지 말고 당신이 이해한 대로 쓴다.
   한 문장으로 못 쓰겠으면 "못 씀"이라 적고 어디서 막혔는지 쓴다.

2. 정의 없이 나온 용어
   문서 안에서 정의되지 않았고, 당신이 원래 아는 것에도 없는 이름·약칭·고유어.
   같은 것을 다른 이름으로 부른 것 같은 곳도 적는다.
   줄 번호와 함께. 뜻을 짐작했으면 짐작한 뜻도 적는다.

3. 추측으로 메운 곳
   읽다가 "아마 이런 뜻이겠지" 하고 넘어간 곳. 지시어(그것, 앞서 본, 그 방식)가
   무엇을 가리키는지 확신이 없던 곳, 비유가 무엇을 뜻하는지 짐작한 곳,
   단계가 건너뛴 것 같은 곳, 수치를 무엇으로 쟀는지 모르는 곳을 포함한다.
   줄 번호, 무엇을 추측했는지, 확신 정도(높음/낮음).
```
